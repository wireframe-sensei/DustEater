# Color Tokens

Extracted verbatim from the Figma variable collection `Colors` (modes: Light, Dark).
Percentages after a hex value are **alpha**. Semantic colors are alpha-based on purpose —
they must composite over whatever is behind them, so do not flatten them to opaque hex.
